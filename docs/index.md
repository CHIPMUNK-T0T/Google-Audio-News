# Google-Audio-News

Google-Audio-News は、運営者が個人で使うためのツールです。

1. 運営者の Google スプレッドシートからニュース原稿を読み取る
2. 原稿を音声合成で音声にし、静止画と合わせて動画にする
3. 動画を運営者自身の YouTube チャンネルに **非公開** でアップロードする

Google アカウントへのアクセスは、YouTube への動画のアップロード（`https://www.googleapis.com/auth/youtube.upload`）だけに使います。運営者以外の人がこのツールを使うことはありません。

- [プライバシーポリシー](privacy.html)
- [ソースコード](https://github.com/CHIPMUNK-T0T/Google-Audio-News)

---

Google-Audio-News is a personal tool used only by its operator. It reads news scripts from the operator's own Google Sheet, turns them into audio and a still-image video, and uploads the video as private to the operator's own YouTube channel. It requests only the `youtube.upload` scope. See the [Privacy Policy](privacy.html).
